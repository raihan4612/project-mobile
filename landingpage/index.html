Fitur Utama

Semua Kebutuhan Akademik dalam Satu Aplikasi

Jelajahi fitur inti SIMAK Mobile yang dapat Anda gunakan setiap hari.

Login
1

Autentikasi Aman & Sesuai Peran

Masuk dengan NIM/email dan password. Sistem mengenali peran Anda sehingga setiap pengguna hanya melihat menu dan data sesuai hak aksesnya.

  • Login & logout dengan token Bearer (Laravel Sanctum)
  • Password ter-hash bcrypt untuk keamanan akun
  • Empat level pengguna: Admin, Petugas, Mahasiswa, Guest
Dashboard
2

Dashboard Statistik Real-Time

Pusat kendali berisi ringkasan data akademik: jumlah buku yang dipinjam, status prestasi, hingga pengajuan beasiswa yang sedang berjalan.

  • Ringkasan statistik disaring otomatis per peran
  • Notifikasi pengguna dengan penanda belum-dibaca
  • Akses cepat ke seluruh modul dari satu layar
Perpustakaan
3

Katalog Buku & Peminjaman Otomatis

Cari buku dari katalog digital, ajukan peminjaman, dan kembalikan langsung dari aplikasi. Denda keterlambatan dihitung otomatis oleh sistem.

  • Pencarian & filter katalog buku cepat
  • Catat peminjaman/pengembalian dengan satu ketukan
  • Denda Rp 1.000/hari terhitung otomatis
Prestasi
4

Input Prestasi & Verifikasi Berjenjang

Catat prestasi Anda dengan unggah sertifikat. Admin memverifikasi melalui alur Pending → Disetujui/Ditolak lengkap dengan riwayat verifikasi.

  • Unggah sertifikat langsung dari HP (kamera/galeri/file)
  • Alur verifikasi berjenjang & transparan
  • Riwayat status prestasi dapat dipantau
Beasiswa
5

Pengajuan & Rekomendasi Beasiswa

Ajukan beasiswa dan dapatkan rekomendasi otomatis berbasis logika Fuzzy Mamdani menggunakan IPK serta tingkat prestasi untuk keputusan yang lebih objektif.

  • Daftar program beasiswa dari admin
  • Rekomendasi otomatis dengan logika Fuzzy Mamdani
  • Pantau status pengajuan secara real-time
Profil
6

Profil & Pengaturan Akun

Kelola data diri dan keamanan akun Anda — ubah profil, perbarui password, dan pantau peran serta akses yang dimiliki.

  • Lihat & ubah data diri
  • Perbarui password dengan aman
  • Informasi peran & hak akses pengguna
Tentang

Kenapa SIMAK Mobile Dikembangkan?

Ringkasan latar belakang, tujuan, target pengguna, dan manfaat sistem.

📜

Latar Belakang

Pengelolaan data akademik sering dilakukan secara manual dan tersebar di beberapa buku register maupun file spreadsheet. Akibatnya data mudah terduplikasi, sulit dicari, dan pemantauan prestasi, peminjaman buku, maupun pengajuan beasiswa menjadi lambat. SIMAK Mobile hadir untuk memusatkan seluruh data dalam satu sistem terintegrasi yang dapat diakses dari perangkat mobile.

🎯

Tujuan

Mendigitalisasi pengelolaan data mahasiswa, perpustakaan, prestasi, dan beasiswa; menyediakan akses informasi real-time bagi mahasiswa dan staf; mempercepat proses verifikasi prestasi dan peminjaman buku; serta membantu pengambilan keputusan pemberian beasiswa melalui rekomendasi otomatis berbasis logika fuzzy.

👥

Target Pengguna

Mahasiswa (melihat data diri, meminjam buku, input prestasi, mengajukan beasiswa), Petugas (mengelola katalog buku dan proses peminjaman/pengembalian), Admin (mengelola seluruh data, verifikasi, hak akses, dan laporan), serta Guest (pengunjung dengan hak baca).

⭐

Manfaat

Akses data kapan saja dan di mana saja; transparansi status pengajuan (prestasi/beasiswa); penghematan waktu input manual; pengurangan duplikasi dan kesalahan data; perhitungan denda keterlambatan otomatis; serta keputusan beasiswa yang lebih objektif berkat rekomendasi otomatis.

Fitur unggulan yang membedakan dari sistem manual maupun aplikasi lain.

🧠

Rekomendasi Beasiswa Fuzzy

Perhitungan rekomendasi beasiswa otomatis dengan metode Fuzzy Mamdani berdasarkan IPK dan skor tingkat prestasi (kampus s/d internasional).

🔔

Notifikasi Pengguna

Notifikasi aplikasi untuk pengguna terkait status prestasi, beasiswa, atau peminjaman, dengan penanda belum-dibaca.

📱

Mobile-First & Responsif

Dibangun dengan Flutter untuk pengalaman asli di Android, ditambah antarmuka web admin yang responsif menggunakan Bootstrap 5.

Instalasi

Langkah Instalasi

Dari pemasangan aplikasi di HP Android hingga setup server backend.

📱 Untuk Pengguna (Android)

  1. Unduh file simak-mobile.apk melalui tombol download di halaman ini.
  2. Buka file APK; jika muncul peringatan, izinkan "Instal aplikasi tidak dikenal" untuk browser.
  3. Tekan Instal dan tunggu hingga selesai.
  4. Buka aplikasi, login dengan NIM/email + password, lalu nikmati fiturnya.
Koneksi internet diperlukan untuk mengakses server API.

🔧 Untuk Developer (Backend)

  1. Clone/salin project praktikum24 lalu jalankan composer install.
  2. Salin .env.example menjadi .env dan sesuaikan konfigurasi database.
  3. Jalankan php artisan key:generate.
  4. Buat database, lalu php artisan migrate --seed untuk tabel + data awal.
  5. Jalankan php artisan serve (default port 8000) dan pastikan API merespons.
  6. Build aplikasi Flutter: flutter build apk --release (tambahkan --dart-define=API_URL=... untuk alamat server).
Spesifikasi

Kebutuhan Sistem, Keamanan & Performa

Detail persyaratan perangkat, aspek keamanan, dan strategi performa.

🖥

Kebutuhan Sistem

Aplikasi: Android 8.0+, RAM 2 GB, ruang 100 MB, koneksi internet.

Server: PHP 8.3+, MySQL, Apache/Nginx, kompatibel shared hosting (InfinityFree).

Pengembangan: Flutter SDK 3.x, Composer, Node.js (opsional untuk build aset).

🔒

Keamanan

Autentikasi token Laravel Sanctum (Bearer token); password di-hash bcrypt; validasi request di sisi server; kontrol akses berbasis peran (RBAC) dengan middleware admin; pembatasan data per pengguna (mahasiswa hanya melihat datanya sendiri); proteksi file unggahan; komunikasi via HTTPS; dan berkas sensitif (.env) tidak terekspos publik.

⚡

Performa

Paginasi (20 data/halaman) agar respons cepat; eager loading relasi untuk menghindari N+1; indeks & foreign key pada kolom relasi; autoloader teroptimasi (--optimize-autoloader); cache & queue berbasis database untuk operasi ringan; tampilan web memakai CDN untuk mengurangi beban server.

Studi Kasus

Sebelum & Sesudah Menggunakan SIMAK

Perbandingan proses manual dengan penggunaan sistem terdigitalisasi.

👎 Sebelum (Manual)

  • Data mahasiswa, buku, dan prestasi dicatat di buku register & spreadsheet terpisah.
  • Pencarian data lambat dan rentan duplikasi/salah input.
  • Peminjaman buku dicatat manual; denda dihitung dengan kalkulasi tangan.
  • Verifikasi prestasi dan pengajuan beasiswa memakan waktu lama karena harus mendatangi bagian administrasi.
  • Monitoring dan pelaporan (mis. siapa peminjam terlambat) sulit dan sering terlambat.

👍 Sesudah (Digital)

  • Seluruh data terpusat dalam satu database dengan relasi yang jelas.
  • Input sekali saja; pencarian & filter cepat langsung dari aplikasi.
  • Peminjaman/pengembalian tercatat otomatis, denda keterlambatan dihitung sistem.
  • Mahasiswa dapat input prestasi & mengajukan beasiswa dari HP; admin memverifikasi secara online.
  • Rekomendasi beasiswa otomatis (Fuzzy Mamdani) mempercepat & membuat keputusan lebih objektif.
  • Dashboard statistik memberikan gambaran kondisi akademik secara real-time.
FAQ

Pertanyaan yang Sering Diajukan

Jawaban singkat untuk pertanyaan umum seputar SIMAK Mobile.

Bagaimana cara login ke aplikasi?
Masukkan NIM atau email beserta password pada halaman login, lalu tekan tombol Masuk. Akun mahasiswa umumnya menggunakan NIM dengan password default password.
Apa saja akun uji coba yang tersedia?
Admin: admin@simak.com / admin123. Petugas: petugas@simak.com / petugas123. Mahasiswa: login pakai NIM dengan password password.
Muncul peringatan "sumber tidak dikenal", bagaimana mengatasinya?
Karena APK diunduh langsung dari browser (bukan Play Store), Android akan meminta izin. Buka Pengaturan → Aplikasi → browser Anda → aktifkan Instal aplikasi tidak dikenal, lalu ulangi instalasi.
Apakah aplikasi ini berbayar?
Tidak. SIMAK Mobile gratis untuk pengguna internal. Biaya hanya berasal dari penyedia hosting dan domain (jika memakai layanan berbayar).
Apakah data saya aman?
Ya. Setiap permintaan API dilindungi token Bearer, password di-hash, akses dibatasi per peran, dan komunikasi menggunakan HTTPS. Mahasiswa hanya dapat melihat data miliknya sendiri.
Apakah tersedia untuk iPhone / iOS?
Proyek ini sudah menyertakan struktur project iOS, namun saat ini distribusi difokuskan pada Android (APK). Versi iOS dapat dibangun saat diperlukan dengan akun developer Apple.
Aplikasi tidak bisa terhubung ke server, kenapa?
Pastikan koneksi internet aktif dan alamat API (API_URL) pada build aplikasi mengarah ke server yang benar. Jika server dalam mode pengembangan di komputer Anda, pastikan php artisan serve berjalan.
